# Historische Referenz für lokalen Zustand und Speicherung

Die drei JavaScript-Dateien stammen aus dem bisherigen Offline-Projekt. Sie zeigen Transaktionsplanung, Schutz gegen doppelte Buchung, eine Speicherung in zwei Slots und die Koordination von Zustandsänderungen.

Sie sind kein fertiger Godot-Spielkern und liefern keine Original-Baukosten, Forschungsabhängigkeiten oder Produktionsrezepte. Ihr Nutzen für Elvenland sind die erprobten Prinzipien. In GDScript werden daraus eigene lokale Dienste mit einem klar definierten Datenmodell.

Die historischen 111 Hosttests bezogen sich auf den gesamten dort geprüften JavaScript-Kontext einschließlich synthetischer Testdaten. Sie sind weder ein Android-Nachweis noch ein Nachweis vollständiger Originalregeln. Siehe `docs/PREVIOUS_CORE_AUDIT.md` und `verification/previous_host_tests.json`.
